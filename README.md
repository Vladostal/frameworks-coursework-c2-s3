# Сравнительный анализ влияния ручного и искусственного обогащения данных на качество и устойчивость обучения моделей машинного обучения


## Данные

- **CEDR-M7**: 9410 русских текстов, 7 эмоций, MIT. [Hugging Face](https://huggingface.co/datasets/Aniemore/cedr-m7)
- **Potholes Detection**: 13 767 фото дорог с рамками ям, формат YOLOv8, CC BY 4.0. [Roboflow](https://universe.roboflow.com/project-ssayl/potholes-detection-d4rma)

Все данные лежат в `data/` и в git не попадают. Датасеты скачивают ноутбуки.

## Ручной сбор

- Тексты: 350 отзывов из App Store на приложения, игры и доставку.
- Фото ям: 100 штук, 15 наших и 85 из [Mendeley](https://doi.org/10.17632/tp95cdvgm8.1) (CC BY 4.0).
  Своих мало, потому что в Москве сложно найти ямы. Источник каждого фото записан в `sources.csv`.

Фото размечали два аннотатора независимо, правила в `annotation/`.

## Запуск

Нужен [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env
```

В `.env` впишите `ROBOFLOW_API_KEY`, он нужен только для ноутбука с ямами.
Откройте ноутбук из `notebooks/` с ядром из `.venv` и выполните ячейки по порядку. Результаты уже сохранены, смотреть можно без запуска.

## Структура

```
notebooks/      загрузка данных и EDA
data/           данные, только локально
annotation/     правила разметки
```
