# Курсовой проект: ручное и ИИ-обогащение данных

Курсовая работа (МАИ, 2 курс). Исследуем, как ручное и искусственное обогащение данных влияет на обучение моделей.

## Данные

- **CEDR-M7**: 9410 русских текстов с эмоциями, 7 классов, лицензия MIT.
  [Источник](https://huggingface.co/datasets/Aniemore/cedr-m7).
- **Potholes Detection**: 13 767 фото дорог с рамками ям, 1 класс, формат YOLOv8, лицензия CC BY 4.0.
  [Источник](https://universe.roboflow.com/project-ssayl/potholes-detection-d4rma).

Данные хранятся локально в `data/raw/` и в git не попадают. Их скачивают сами ноутбуки.

## Запуск

Нужен Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
echo 'ROBOFLOW_API_KEY=ваш_ключ' > .env    # нужен только для ноутбука с ямами
```

Откройте `notebooks/text.ipynb` или `notebooks/images.ipynb` и выполните ячейки по порядку.
Ноутбуки поставят библиотеки и скачают данные. Результаты уже сохранены в ноутбуках, их можно смотреть без запуска.

## Структура

```
notebooks/      загрузка данных и EDA
pyproject.toml  библиотеки
```

## Разметка отзывов

Готовый датасет: `data/manual/text/dataset.csv`. В нём 350 отзывов,
по 50 на каждый класс. Формат: `text,label`.

Для просмотра и выбора классов откройте `data/manual/text/annotator.html`
двойным щелчком в браузере. Страница работает без сервера и интернета.

- Кнопки или клавиши 1–7 выбирают класс и переводят к следующему отзыву.
- Стрелки влево/вправо листают тексты, клавиша 0 убирает выбор.
- Текущие значения автоматически сохраняются в этом браузере.
- «Скачать CSV» выгружает только тексты с выбранными классами, колонки `text,label`.
- «Открыть CSV» загружает другой набор или сохранённую разметку.
- «Начать новую разметку» очищает выбранные классы в интерфейсе.

В интерфейсе `enthusiasm` отображается как «Удивление». Остальные классы:
`neutral`, `happiness`, `sadness`, `fear`, `anger`, `disgust`.

Изменения в браузере не перезаписывают файл на диске: после завершения
нужно скачать CSV. Скачанный файл можно сохранить как `dataset.csv`.
