# Курсовой проект: ручное и ИИ-обогащение данных

Курсовая работа (МАИ, 2 курс). Исследуем, как ручное и искусственное обогащение данных влияет на обучение моделей.

## Данные

- **CEDR-M7**: 9410 русских текстов с эмоциями, 7 классов, лицензия MIT.
  [Источник](https://huggingface.co/datasets/Aniemore/cedr-m7).
- **Potholes Detection**: 13 767 фото дорог с рамками ям, 1 класс, формат YOLOv8, лицензия CC BY 4.0.
  [Источник](https://universe.roboflow.com/project-ssayl/potholes-detection-d4rma).

Данные хранятся локально в `data/raw/` и в git не попадают. Их скачивают сами ноутбуки.

## Запуск

Нужен Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
echo 'ROBOFLOW_API_KEY=ваш_ключ' > .env    # нужен только для ноутбука с ямами
```

Откройте `notebooks/text.ipynb` или `notebooks/images.ipynb` и выполните ячейки по порядку.
Ноутбуки поставят библиотеки и скачают данные. Результаты уже сохранены в ноутбуках, их можно смотреть без запуска.

## Структура

```
notebooks/      загрузка данных и EDA
pyproject.toml  библиотеки
```

## Суть курсовой и текущий этап

По материалам этого репозитория задача — исследовать влияние реального и
ИИ-обогащения на две задачи: распознавание эмоций в русском тексте и обнаружение
дорожных ям. Пока выполнен EDA. Обучение и сравнение вариантов ещё не проведены.
Полного задания преподавателя, обязательных моделей и квот сбора в репозитории нет.

План сравнения: исходная обучающая выборка; она же с добавленными реальными
размеченными примерами; она же с синтетическими примерами. Для честного сравнения
нужны одинаковые модели, настройки, число добавленных примеров и несколько seed.
Контрольная выборка должна оставаться общей для всех вариантов. Это план
эксперимента, а не выписка из отсутствующего задания преподавателя.

EDA уже обнаружил утечки: 14 текстов test CEDR-M7 встречаются в train, а 458 из
891 изображений test имеют копии в train. До обучения нужно устранить эти
пересечения. Для текста следует смотреть macro-F1 и качество по каждому классу:
в train лишь 16 примеров disgust. Для изображений — mAP и качество на мелких ямах.

## Новые отзывы для CEDR-M7

Реальные отзывы собираются из публичных RSS российского App Store по 12
приложениям: мессенджерам, картам, доставке, маркетплейсам, музыке и госуслугам.
Это новый домен относительно исходных новостей, блогов и твитов CEDR-M7.
Эффект добавления данных и смены домена при интерпретации результатов нужно учитывать отдельно.

| Файл | Содержание |
| --- | --- |
| `data/manual/text/collected.csv` | Текст, ID, URL источника, дата доступа и лицензия; исходные 5 колонок сохранены |
| `data/manual/text/metadata.csv` | ID отзыва в App Store, приложение, заголовок, звёзды, дата обновления и хеши источника |
| `data/manual/text/annotations.csv` | Тексты и пустые поля двух разметчиков, итоговых меток и примечаний |
| `data/manual/text/collection_report.json` | Объём, отсеянные записи, даты, распределения и манифест источников |
| `scripts/collect_reviews.py` | Повторяемый сбор и проверка дубликатов |

Запуск сбора (в активированном окружении):

```bash
python -m pip install 'pyarrow>=15' 'requests>=2.31,<3'
python scripts/collect_reviews.py --batch 2026-11-15 --pages 3 --limit 1000
```

Сначала загружается CEDR-M7 в той же зафиксированной ревизии, что и в `text.ipynb`.
Новые отзывы проверяются против **train и test**. Исключаются нормализованные
совпадения и близкие копии по Jaccard ≥ 0,90 на тройках слов для текстов от 8 слов.
Это проверка текстовых копий; смысловые перефразы она не гарантирует обнаружить.

Сохраняются отзывы длиной 40–1500 символов, минимум с 6 русскими словами и долей
русских букв от 65%. Отзывы с явными ссылками, email, телефонами или @никами
отсеиваются. Регистр, пунктуация, эмодзи и отрицания сохраняются, пробелы
нормализуются. В локальных снимках остаются оригинальные тексты без имён и
профилей авторов. Снимки и исходный CEDR лежат в `data/raw/` и исключены из git.

Отбор с seed 42 чередует приложения и группы оценок 1–2, 3, 4–5. Это выборка для
разметки, не оценка долей эмоций среди пользователей. Звёзды остаются только в
метаданных; они **не превращаются в метки эмоций**. Лексические признаки в отчёте
также служат только ориентиром для дополнительного поиска.

Сбор можно повторить без сети на сохранённых снимках:

```bash
python scripts/collect_reviews.py --batch 2026-11-15 --pages 3 --limit 1000 --offline
python -m unittest discover -s tests
```

Повторный запуск сохраняет уже собранные записи и заполненные поля разметки.
`--limit` задаёт целевой общий объём, а не число добавлений. Для новой загрузки
используйте другое имя `--batch`; ленты со временем меняются.

Для разметки используются исходные имена классов CEDR-M7: `neutral`, `happiness`,
`sadness`, `enthusiasm`, `fear`, `anger`, `disgust`; несколько меток разделяются `;`.
Смысл `enthusiasm` нужно согласовать до разметки: EDA показывает, что в этом наборе
он часто соответствует удивлению. Рекомендуется две независимые разметки с
разбором расхождений. До этого отзывы не следует добавлять в обучение.

Лицензия на тексты отзывов в RSS не указана: поле `license=not_specified`.
Лицензия MIT исходного CEDR-M7 на собранные отзывы не переносится.
